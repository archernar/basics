Master the macOS Terminal.

Built on a powerful UNIX foundation, the command line is your direct gateway to the core of macOS. This interactive guide will walk you through the essentials of the Terminal, Zsh, and file management, turning you into a command-line pro.

Meet the Core Concepts

On macOS, the relationship is simple: Terminal is the application window, and Zsh is the powerful shell engine running inside it. Click each card to learn more.

🖥️ Terminal App

The modern, tabbed host application for all your command-line shells.

⚡️ Z Shell (Zsh)

The powerful, modern shell that interprets your commands.

Essential Command Cheatsheet

                
A quick reference for the most common file and directory operations in Zsh.

            

            

                

                    
                        

                            Task
                            Command
                            Example
                        

                    
                    
                        

                            List Contents
                            ls
                            ls -la
                        

                        

                            Change Directory
                            cd
                            cd Documents
                        

                        

                            Create Directory
                            mkdir
                            mkdir NewProject
                        

                        

                            Create Empty File
                            touch
                            touch notes.txt
                        

                        

                            Copy Item
                            cp
                            cp notes.txt notes_backup.txt
                        

                         

                            Move / Rename Item
                            mv
                            mv notes.txt old_notes.txt
                        

                        

                            Remove File
                            rm
                            rm old_notes.txt
                        

                        

                            Remove Directory
                            rm -r
                            rm -r OldProject
                        

                        

                            View File Content
                            cat
                            cat config.yml
                        

                    
                

            

        


        

            
Your Journey Begins

            
You've mastered the basics. Now, continue your journey by exploring these powerful tools that build on your new command-line skills.

            

                

                    
🍺 Homebrew

                    
Use "the missing package manager for macOS" to easily install developer tools, programming languages, and applications directly from your terminal.

                

                

                    
🎨 Oh My Zsh

                    
Explore this open-source framework for managing your Zsh configuration. It comes with thousands of helpful plugins, themes, and functions.

                

                

                    
📜 Shell Scripting

                    
Combine commands into `.sh` script files to automate repetitive tasks, like setting up a new project or backing up your work. This is where the real power lies.
