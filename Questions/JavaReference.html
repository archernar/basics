Basic Structure & Syntax

This section covers the fundamental syntax and structure of a Java program. Every Java application has an entry point in the `main` method, and all code is organized within classes.

Main Method & Class

public class MyClass {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Variables & Constants

// A variable whose value can change
int userAge = 25;

// A constant whose value cannot change
final double PI = 3.14159;

Operators

Operators perform operations on variables and values. This section covers the most common categories, from arithmetic to logical operators.

Arithmetic: `+ - * / %`

Perform basic mathematical calculations.

Relational: `== != > < >= <=`

Compare two values, resulting in a boolean.

Logical: `&& || !`

Combine boolean expressions.

Assignment: `= += -= *= /=`

Assign values to variables.

Control Flow

Control flow statements direct the order in which code is executed. Use conditionals to make decisions and loops to repeat actions.

// If-Else-If statement
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else {
    grade = 'C';
}

// Switch statement (Java 14+)
String dayType = switch (dayOfWeek) {
    case "Saturday", "Sunday" -> "Weekend";
    case "Monday" -> "Start of week";
    default -> "Midweek";
};
// For loop
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// Enhanced for-each loop
int[] numbers = {1, 2, 3};
for (int num : numbers) {
    System.out.println(num);
}

// While loop
int count = 0;
while (count < 3) {
    System.out.println("Looping...");
    count++;
}

Object-Oriented Programming (OOP)

OOP is a paradigm based on the concept of "objects". These are the four core principles of OOP in Java. Click on each card to learn more about the concept.

Encapsulation

Bundling data (fields) and methods that operate on the data into a single unit, a class. Access to the data is restricted via `private` fields and controlled through `public` getters and setters.

Inheritance

A mechanism where a new class (subclass) acquires the properties and behaviors of an existing class (superclass) using the `extends` keyword, promoting code reuse.

Polymorphism

The ability of an object to take on many forms. A reference variable of a superclass type can point to an object of any of its subclasses, allowing methods to be used flexibly.

Abstraction

Hiding complex implementation details and showing only the essential features of the object. Achieved using `abstract` classes and `interfaces`.

Strings & Arrays

These are two of the most fundamental data structures for storing collections of data. Strings are immutable sequences of characters, while arrays are fixed-size containers for elements of the same type.

String greeting = "Hello World";
int len = greeting.length(); // 11
char firstChar = greeting.charAt(0); // 'H'
String sub = greeting.substring(6); // "World"
boolean hasHello = greeting.contains("Hello"); // true

// Use StringBuilder for mutable strings
StringBuilder sb = new StringBuilder("Java");
sb.append(" is cool"); // "Java is cool"
// Declare and initialize an array
int[] numbers = new int[5]; // size 5, default values 0
String[] fruits = {"Apple", "Banana", "Cherry"};

// Access an element
String firstFruit = fruits[0]; // "Apple"
numbers[0] = 100;

// Get the length
int size = fruits.length; // 3

Collections Framework

A powerful framework for storing and manipulating groups of objects. These dynamic data structures offer more flexibility than arrays. Explore the primary interfaces below.

An ordered collection that allows duplicate elements. `ArrayList` is the most common implementation.

import java.util.ArrayList;
import java.util.List;

List<String> names = new ArrayList<>();
names.add("Alice");
names.add("Bob");
names.add(0, "Zack"); // ["Zack", "Alice", "Bob"]
String secondName = names.get(1); // "Alice"

An unordered collection that does not allow duplicate elements. `HashSet` is fast and commonly used.

import java.util.HashSet;
import java.util.Set;

Set<Integer> uniqueNumbers = new HashSet<>();
uniqueNumbers.add(5);
uniqueNumbers.add(10);
uniqueNumbers.add(5); // This is ignored
boolean hasTen = uniqueNumbers.contains(10); // true

An object that maps keys to values. Keys must be unique. `HashMap` is the standard implementation.

import java.util.HashMap;
import java.util.Map;

Map<String, Integer> studentScores = new HashMap<>();
studentScores.put("David", 95);
studentScores.put("Eve", 89);
int davidsScore = studentScores.get("David"); // 95
studentScores.remove("Eve");

Exception Handling

Java's mechanism to handle runtime errors gracefully. The `try-catch-finally` block is used to manage exceptions and prevent program crashes.

try {
    // Code that might throw an exception
    int[] myNumbers = {1, 2, 3};
    System.out.println(myNumbers[10]); // This will fail
} catch (ArrayIndexOutOfBoundsException e) {
    // Handle the specific error
    System.err.println("Error: Index is out of bounds.");
} finally {
    // This code always executes, for cleanup
    System.out.println("The 'try catch' is finished.");
}

Input/Output (I/O)

Mechanisms for reading from and writing to data sources like the console or files.

Reading Console Input

import java.util.Scanner;
Scanner scanner = new Scanner(System.in);
System.out.print("Enter your name: ");
String name = scanner.nextLine();
scanner.close();

Writing to a File

import java.io.FileWriter;
import java.io.IOException;

try (FileWriter writer = new FileWriter("output.txt")) {
    writer.write("Hello from Java!");
} catch (IOException e) {
    e.printStackTrace();
}

Modern Java Features (Java 8+)

Java has evolved significantly. These features, introduced from version 8 onwards, enable more concise, functional, and expressive code.

Lambda Expressions

Anonymous functions that implement a functional interface. `(params) -> expression`

list.forEach(item -> System.out.println(item));

Stream API

A declarative API for processing collections in a functional style (filter, map, reduce).

long count = list.stream().filter(s -> s.startsWith("A")).count();

Optional

A container object to represent a value that may be absent, helping to avoid `NullPointerException`.

Optional<String> name = Optional.ofNullable(null);
name.ifPresent(System.out::println);

Records (Java 16+)

A concise syntax for creating immutable data carrier classes.

public record User(String username, String role) {}
