## Java Exercises 
### Overriding vs. Hiding Fields 

    Create a 'Super' class with an instance variable 'int x = 10'. Create a 'Sub' class 
    with its own 'int x = 20'. Create a method in 'Super' that prints 'x'. Show that 
    even when called on a 'Sub' object, it prints 10, because fields are hidden, 
    not overridden.
