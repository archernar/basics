## Java Exercises 
### Static Method Hiding 

    Create a 'Parent' class with a 'static' method 'getInfo()'. Create a 'Child' class 
    with its own 'static' method 'getInfo()'. Demonstrate that calling the method 
    on a 'Parent' reference holding a 'Child' object invokes the 'Parent' version, proving 
    static methods are hidden, not overridden.
