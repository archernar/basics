## Java Exercises 
### Employee Profile Constructor 

    Create an `Employee` class with private instance variables for `name` (String) and 
    `employeeID` (int). Write a constructor that accepts a name and employeeID as 
    parameters. Inside the constructor, the parameter names must be identical to the 
    instance variable names. You **must** use the `this` keyword to distinguish between 
    the instance variables and the parameters (e.g., `this.name = name;`). Also 
    create a `getProfile()` method that returns a formatted string with the employee's 
    details. In main, create an `Employee` object and call `getProfile()` to verify 
    it was constructed correctly.
