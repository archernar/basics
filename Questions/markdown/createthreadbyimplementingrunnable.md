## Java Exercises 
### Create Thread by Implementing 'Runnable' 

    Create a class 'MyRunnable' that implements the 'java.lang.Runnable' interface. Implement 
    the 'run()' method to print the alphabet from A to Z. In 'main', create 
    a 'Thread' instance, pass 'MyRunnable' to its constructor, and start the thread.
