## Java Exercises 
### Implementing a Simple HTTP GET Client 

    Without using 'HttpClient' or 'URLConnection', open a 'Socket' to a web server (e.g., 
    'example.com' on port 80). Manually write a raw HTTP/1.1 GET request string 
    to the output stream and read/print the raw HTTP response from the input stream.
