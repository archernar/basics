## Java Exercises 
### Implement a 'Future' and 'Promise' from Scratch 

    Build your own implementation of a 'Future' and 'Promise' to understand asynchronous 
    operations. A 'Promise' can be completed with a value or an error, and the associated 
    'Future' allows a consumer to retrieve the result, blocking if it's not 
    yet available.
