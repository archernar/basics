## Java Exercises 
### Pet Shelter Roster 

    Create a program to manage a roster of pets at an animal shelter. First, design a 
    `Pet` class with private instance variables for `name` (String), `species` (String, 
    e.g., 'Dog', 'Cat'), and `age` (int). The class should have a constructor and 
    public getter methods for all fields. In your `main` method (in a different class), 
    create an array of `Pet` objects. Populate the array with at least 5 different 
    `Pet` instances. Then, implement a search feature: prompt the user to enter 
    a species. Your program must then loop through the array and print the name and 
    age of all pets that match the specified species. If no pets of that species are 
    found, it should print a message indicating that.
