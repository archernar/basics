## Java Exercises 
### Animal Sounds 

    Create a base class 'Animal' with a method 'makeSound()'. Create subclasses like 
    'Dog', 'Cat', and 'Cow', each overriding 'makeSound()' to print 'Woof', 'Meow', 
    and 'Moo' respectively. Demonstrate polymorphism by calling the method on an array 
    of 'Animal' objects.
