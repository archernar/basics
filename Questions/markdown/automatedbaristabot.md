## Java Exercises 
### Automated Barista Bot 

    You are programming a simple automated barista for a coffee shop. The program should 
    first ask the user to choose a drink: Coffee, Latte, or Cappuccino. Then, it 
    should ask for the size: Small, Medium, or Large. Based on the choices, calculate 
    the price. Base prices are: Coffee ($2.50), Latte ($3.50), Cappuccino ($3.75). 
    Size modifiers are: Small (no change), Medium (add $0.75), Large (add $1.25). 
    After calculating the price, the program should ask if the user wants an extra shot 
    of espresso for $1.15. Your program must use a combination of if/else statements 
    and a switch statement to determine the base price and apply the modifiers. 
    Finally, display a summary of the order and the total cost formatted to two decimal 
    places.
