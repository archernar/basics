## Java Exercises 
### Pessimistic vs. Optimistic Locking in JPA 

    In a JPA application, demonstrate both pessimistic and optimistic locking. For pessimistic 
    locking, use '@Lock(LockModeType.PESSIMISTIC_WRITE)'. For optimistic, 
    use the '@Version' annotation and show how an 'OptimisticLockException' is thrown 
    on concurrent modification.
