### Overriding a Method that is Overloaded 

    Create a 'Printer' class with 'print(Object o)' and 'print(String s)'. Create a 'FancyPrinter' 
    subclass that overrides *only* 'print(String s)'. Demonstrate how 
    calls to 'print()' are resolved for different argument types.
