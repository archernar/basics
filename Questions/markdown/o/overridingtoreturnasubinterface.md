## Java Exercises 
### Overriding to Return a Sub-Interface 

    Create an interface 'Data' and a sub-interface 'RichData'. Create a class 'DataProvider' 
    with a method 'fetch()' that returns 'Data'. Create a subclass 'RichDataProvider' 
    that overrides 'fetch()' to return 'RichData'.
