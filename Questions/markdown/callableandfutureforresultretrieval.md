## Java Exercises 
### Callable and Future for Result Retrieval 

    Rewrite the 'Retrieving Data from a Thread' exercise using 'ExecutorService' and 
    'Callable&ltV&gt'. Submit the 'Callable' to get a 'Future&ltV&gt' object. Use 'future.get()' 
    to retrieve the result, which blocks until the computation is complete.
