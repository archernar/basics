## Java Exercises 
### Secure Bank Account 

    Design a `BankAccount` class that is fully encapsulated. It should have a private 
    `balance` (double) and a private `accountNumber` (String). Provide a public constructor 
    and public getter methods. The key part of this problem is to create a 
    public `deposit(double amount)` method and a public `withdraw(double amount)` method. 
    The `deposit` method must not allow negative amounts. The `withdraw` method 
    must not allow a negative amount and must not allow an overdraft (withdrawing 
    more than the current balance). Both methods should return a boolean indicating 
    if the transaction was successful.
