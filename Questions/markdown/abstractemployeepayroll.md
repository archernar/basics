## Java Exercises 
### Abstract Employee Payroll 

    Create an abstract class `Employee` with properties like `name` and `employeeId`, 
    and an abstract method `double calculatePay()`. Create two concrete subclasses: 
    `SalariedEmployee` (with a fixed weekly salary) and `HourlyEmployee` (with an hourly 
    rate and hours worked). Implement the `calculatePay()` method in each subclass. 
    In your main method, create an array of `Employee` objects containing instances 
    of both subclasses and calculate the total payroll for the week.
