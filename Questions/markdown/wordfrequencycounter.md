## Java Exercises 
### Word Frequency Counter 

    Write a program that reads a block of text (you can hardcode it into a String variable) 
    and counts the frequency of each word. The program should be case-insensitive 
    (i.e., 'The' and 'the' count as the same word) and should ignore basic punctuation. 
    You must use a `HashMap&ltString, Integer&gt` to store the words and their 
    counts. After processing the text, the program should print each unique word 
    followed by its count.
