## Java Exercises 
### Movie Database Loader 

    You are given a text file `movies.csv`. Each line represents a movie with the format: 
    `Title,Director,Year`. Write a program that reads this file line by line, splits 
    each line by the comma, and uses the data to create `Movie` objects (you'll 
    need to create this class). Store these `Movie` objects in an `ArrayList`. After 
    reading the entire file, iterate through the list and display the details of 
    each movie. Your test `movies.csv` file should contain at least 5 movies.
