## Java Exercises 
### Library Book Management 

    Design a `Book` class to model a book in a library. The `Book` class must have the 
    following private instance variables: `title` (String), `author` (String), and 
    `isbn` (String). It should have a constructor that initializes these three variables. 
    It should also include public 'getter' methods for all three variables (e.g., 
    `getTitle()`). Finally, include a public method called `displayBookInfo()` 
    that prints the book's details to the console in a user-friendly format (e.g., 'Title: 
    [title], Author: [author], ISBN: [isbn]'). In your `main` method (in a separate 
    class), create at least three different `Book` objects with unique data. 
    Then, call the `displayBookInfo()` method for each book object to demonstrate that 
    your class works correctly.
