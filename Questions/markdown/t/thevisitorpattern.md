## Java Exercises 
### The Visitor Pattern 

    Simulate the visitor pattern. Create a 'DocumentPart' interface with an 'accept(Visitor 
    v)' method. Create 'Paragraph' and 'Image' classes implementing it. Create 
    a 'Visitor' interface with 'visit(Paragraph p)' and 'visit(Image i)'. The 'accept' 
    methods will call the correct overridden 'visit' method on the visitor.
