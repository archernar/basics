## Java Exercises 
### Template Method Pattern 

    Create an abstract 'DataMiner' class with a non-overridable 'mine()' method (the 
    template). This method should call several abstract helper methods like 'openFile()', 
    'extractData()', and 'closeFile()'. Create 'PDFMiner' and 'CSVMiner' subclasses 
    that override the helper methods.
