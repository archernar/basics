## Java Exercises 
### Simple Blocking Queue with 'wait()' and 'notifyAll()' 

    Implement a thread-safe blocking queue of a fixed size from scratch. The 'put()' 
    method should block if the queue is full, and the 'take()' method should block if 
    it's empty. Use 'wait()', 'notifyAll()', and a shared lock.
