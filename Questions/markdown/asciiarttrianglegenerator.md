## Java Exercises 
### ASCII Art Triangle Generator 

    Write a program that prompts the user for a character and an integer representing 
    the height of a triangle. The program should then use nested loops to print a right-aligned 
    triangle of that character. For example, if the user enters '*' and 
    a height of 5, the output should be: \n *\n **\n ***\n ****\n*****
