## Java Exercises 
### Daily Sales Report Aggregator 

    Write a program that reads a text file named 'sales.txt'. Each line in this file 
    contains a product name followed by a comma and the amount of the sale (e.g., 'Laptop,1200.50'). 
    Your program must read the entire file, calculate the total sales 
    amount for the day, and count how many products were sold. After processing the 
    file, it should print the total sales and the total number of transactions to 
    the console. You will need to create a sample 'sales.txt' file with at least 5 
    entries to test your program.
