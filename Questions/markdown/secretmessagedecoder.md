## Java Exercises 
### Secret Message Decoder 

    Create a program that decodes a secret message using a simple substitution cipher. 
    The cipher works by replacing each letter in the message with the letter that 
    is 5 positions before it in the alphabet (e.g., 'f' becomes 'a', 'g' becomes 'b'). 
    The substitution should 'wrap around' from the beginning of the alphabet to the 
    end (e.g., 'c' becomes 'x'). The program should handle both uppercase and lowercase 
    letters independently, preserving their case. Any character that is not a 
    letter (e.g., spaces, punctuation, numbers) should remain unchanged in the output. 
    Your program should prompt the user for an encoded message as a String, then 
    iterate through the string, apply the decoding logic to each character, build the 
    decoded string, and finally print the result.
