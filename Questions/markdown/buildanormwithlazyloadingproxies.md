## Java Exercises 
### Build an ORM with Lazy Loading Proxies 

    Build a rudimentary Object-Relational Mapper (ORM). When fetching an object with 
    a one-to-many relationship (e.g., a 'User' with a list of 'Posts'), use a dynamic 
    proxy to implement lazy loading for the list of posts. The list is only fetched 
    from the database when a method is first called on it.
