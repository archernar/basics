## Java Exercises 
### 'hashCode()' Impact on HashSet 

    Create a 'Product' class with a 'productId' field. Override 'equals()' based on 'productId' 
    but *do not* override 'hashCode()'. Add two equal 'Product' objects to 
    a 'HashSet' and observe the set's size. Now, correctly override 'hashCode()' and 
    repeat.
