## Java Exercises 
### Lambda Metafactory and Method Handles 

    Explore Java's low-level APIs for dynamic language support. Use 'java.lang.invoke.MethodHandles' 
    and 'LambdaMetafactory' to dynamically create and invoke a lambda 
    expression that is equivalent to a hard-coded one. This is an advanced exercise 
    in JVM mechanics.
