## Java Exercises 
### BattleGrid Ship Locator 

    You are given a 10x10 2D integer array representing a BattleGrid. In this grid, a 
    '1' represents part of a hidden ship, and a '0' represents empty water. Write a 
    program that prompts the user to enter a row and a column coordinate (0-9). The 
    program must then check that coordinate on the grid. If the coordinate contains 
    a '1', it should print 'Hit!'. If it contains a '0', it should print 'Miss!'. The 
    program should also validate the user's input to ensure they enter numbers between 
    0 and 9. You must pre-populate the 2D array with a few 'ships' in your code 
    for testing.
