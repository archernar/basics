## Java Exercises 
### Thread Priority 

    Create two threads of the same 'Runnable' type. Use 'setPriority()' to give one thread 
    'Thread.MIN_PRIORITY' and the other 'Thread.MAX_PRIORITY'. Have both threads 
    perform a CPU-intensive task. Observe the output to see if priority affects scheduling 
    (results may vary by OS).
