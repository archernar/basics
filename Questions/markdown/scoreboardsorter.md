## Java Exercises 
### Scoreboard Sorter 

    Create a `Player` class with `name` (String) and `score` (int) fields. In your main 
    program, create an array of `Player` objects with various names and scores. Write 
    a method that implements a simple sorting algorithm (like **Bubble Sort**) 
    to sort the array of players in **descending order** based on their score. After 
    sorting, loop through the array and print out a ranked list of players and their 
    scores, from highest to lowest.
