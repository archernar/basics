## Java Exercises 
### Abstracting a Default Method 

    Create an interface 'Runnable' with a 'default void run()'. Create a sub-interface 
    'ScheduledRunnable' that extends 'Runnable' and overrides 'run()' to be an 'abstract' 
    method, forcing all implementers of 'ScheduledRunnable' to provide their 
    own version.
