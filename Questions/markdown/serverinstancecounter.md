## Java Exercises 
### Server Instance Counter 

    Create a class named `Server`. This class should have an **instance** variable `serverID` 
    (String) to uniquely identify each server object. It should also have a 
    **static** integer variable `serverCount` that tracks the total number of `Server` 
    objects that have been created. In the constructor of the `Server` class, you 
    should assign a unique ID and increment the static `serverCount`. Write a main 
    method that creates three `Server` objects and then prints the final value of `serverCount` 
    to show how many instances were created.
