## Java Exercises 
### Composite Pattern for a GUI Layout 

    Model a GUI layout system using the Composite pattern. Create a 'Component' interface 
    and 'Leaf' elements like 'Button' and 'TextField'. Create 'Composite' elements 
    like 'Panel' and 'Window' that can contain other components, allowing you to 
    treat individual objects and compositions uniformly.
