## Java Exercises 
### Chaos Engineering with a Chaos Monkey 

    Simulate a 'Chaos Monkey'. Write an application that periodically and randomly 'disables' 
    components of a larger (simulated) distributed system. The goal is to test 
    the system's resilience and fault tolerance. For example, a client that randomly 
    throws 'IOException' to simulate network failure.
