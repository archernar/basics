## Java Exercises 
### Recursive Factorial Calculator 

    Write a program that calculates the factorial of a non-negative integer using recursion. 
    A factorial, denoted by n!, is the product of all positive integers up to 
    n (e.g., 5! = 5 * 4 * 3 * 2 * 1 = 120). Your program must include a public static 
    method `long factorial(int n)` that implements the recursive logic. The base 
    case for the recursion is when n is 0, in which case the method should return 1. 
    The main method should prompt the user for an integer, call the recursive method, 
    and print the result.
