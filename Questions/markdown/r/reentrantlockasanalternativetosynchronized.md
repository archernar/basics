### ReentrantLock as an Alternative to 'synchronized' 

    Rewrite the 'Counter' exercise using 'java.util.concurrent.locks.ReentrantLock'. 
    Show how to use 'lock()' and 'unlock()' in a 'try-finally' block to achieve the 
    same thread safety as a 'synchronized' method.
