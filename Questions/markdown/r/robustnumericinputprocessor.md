## Java Exercises 
### Robust Numeric Input Processor 

    Write a program that asks the user to enter their age. Your program must be robust 
    enough to handle cases where the user enters non-numeric text (e.g., 'twenty') 
    instead of a number. You must use a `try-catch` block to gracefully handle the 
    `InputMismatchException` that occurs when the `Scanner` cannot parse an integer. 
    If the user enters invalid input, the program should print an error message and 
    prompt them to try again. The program should loop until valid integer input is 
    received.
