## Java Exercises 
### Scientific Constants Library 

    Create a class named `PhysicsConstants` that acts as a library for common physical 
    constants. This class should not be instantiable (hint: use a private constructor). 
    Inside the class, define several `public static final` constants, such as 
    `SPEED_OF_LIGHT` (299792458.0 m/s), `GRAVITATIONAL_CONSTANT` (6.67430e-11 N(m/kg)^2), 
    and `PLANCK_CONSTANT` (6.62607015e-34 J·s). Write a separate main class that 
    uses these constants to perform a simple calculation, such as calculating the 
    energy of a photon using E=hf (Energy = Planck's constant * frequency).
