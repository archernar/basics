## Java Exercises 
### Strategy Design Pattern: Payment System 

    Design a payment processing system using the Strategy pattern. Define a 'PaymentStrategy' 
    interface with a 'pay()' method. Implement concrete strategies for 'CreditCardPayment', 
    'PayPalPayment', and 'CryptoPayment'. A 'ShoppingCart' class should 
    use a selected strategy to process payments.
