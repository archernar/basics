## Java Exercises 
### Versioned Object Serialization 

    Create a class that is 'Serializable'. Serialize an instance to a file. Now, modify 
    the class (e.g., add a new field, remove an old one) and try to deserialize the 
    old file. Implement 'serialVersionUID' and methods like 'readObject' to handle 
    the version mismatch gracefully.
