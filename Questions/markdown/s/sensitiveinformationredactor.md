## Java Exercises 
### Sensitive Information Redactor 

    Write a program that redacts sensitive information from a block of text. Create a 
    method that accepts a String of text and an array of keywords to be redacted. The 
    method should loop through the keywords and replace every occurrence of each 
    keyword in the text with a string of asterisks of the same length (e.g., 'password' 
    becomes '********'). The replacement should be case-insensitive. In your main 
    method, define a sample text and a list of sensitive words (like 'email', 'password', 
    'social security'), and print the redacted version of the text.
