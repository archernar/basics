## Java Exercises 
### Student Grade Analyzer 

    You are a teaching assistant and need to write a program to perform a simple analysis 
    of student grades. The program should first ask the user for the number of 
    students in a class. Then, it should prompt the user to enter the final grade (as 
    a double) for each student and store these grades in an array. Once all grades 
    are entered, the program must calculate and display the following statistics: the 
    average grade for the class, the highest grade, the lowest grade, and the number 
    of students who scored above the class average. The output should be clearly 
    labeled and all grade values should be displayed with two decimal places.
