## Java Exercises 
### State Pattern for a Vending Machine 

    Model a vending machine using the State design pattern. Create a 'State' interface 
    and concrete state classes like 'NoCoinState', 'HasCoinState', 'SoldState', and 
    'EmptyState'. The machine's behavior ('insertCoin()', 'selectItem()') changes 
    based on its current state object.
