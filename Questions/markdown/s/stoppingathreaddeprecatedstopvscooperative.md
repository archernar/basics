    Discuss why 'Thread.stop()' is deprecated. Then, implement two versions of a stoppable 
    thread: one that uses the unsafe 'stop()' method (for demonstration only), 
    and a correct one that uses a 'volatile boolean' flag for cooperative cancellation.
