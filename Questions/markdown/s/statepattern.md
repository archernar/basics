## Java Exercises 
### State Pattern 

    Create a 'State' interface with a 'handle()' method. Create an 'Order' class that 
    has a 'State' object. Create 'NewOrderState' and 'ShippedOrderState' classes that 
    implement 'handle()' differently. The order's behavior changes based on which 
    state object it holds, simulating an override.
