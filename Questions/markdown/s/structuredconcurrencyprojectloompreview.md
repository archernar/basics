## Java Exercises 
### Structured Concurrency (Project Loom Preview) 

    Using a version of Java with Project Loom features enabled, implement a task that 
    involves concurrent sub-tasks (e.g., fetching data from multiple web services). 
    Use Structured Concurrency APIs ('StructuredTaskScope') to manage the lifecycle 
    of these sub-tasks, ensuring they are all completed or cancelled together.
