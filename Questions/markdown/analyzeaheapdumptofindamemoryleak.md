## Java Exercises 
### Analyze a Heap Dump to Find a Memory Leak 

    Write a program with a deliberate memory leak (e.g., a static list that is never 
    cleared). Run the program until it throws an 'OutOfMemoryError', capturing a heap 
    dump using JVM flags. Use a tool like Eclipse Memory Analyzer (MAT) to analyze 
    the dump and identify the leak.
