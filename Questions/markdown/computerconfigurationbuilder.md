## Java Exercises 
### Computer Configuration Builder 

    Model a computer system using composition. Create classes for `CPU` (with properties 
    like `speedInGhz` and `cores`) and `RAM` (with `sizeInGb`). Then, create a `Computer` 
    class that 'has-a' `CPU` object and a `RAM` object as private instance 
    variables. The `Computer`'s constructor should accept `CPU` and `RAM` objects to 
    initialize it. Add a method to the `Computer` class called `displaySpecs()` that 
    prints the specifications of its components.
