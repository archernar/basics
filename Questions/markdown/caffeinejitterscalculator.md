## Java Exercises 
### Caffeine Jitters Calculator 

    Create a program that calculates the total amount of caffeine consumed and estimates 
    when it will be fully metabolized. The program should prompt the user for three 
    inputs: the number of cups of coffee, the number of cans of soda, and the number 
    of cups of tea they've consumed today. Assume coffee has 95mg of caffeine, 
    soda has 40mg, and tea has 26mg. The program must then calculate and display the 
    total caffeine intake in milligrams. Additionally, assuming the half-life of caffeine 
    is 5 hours, calculate and display the approximate number of hours it will 
    take for the caffeine to be less than 10mg in the body. The formula for decay can 
    be simplified: for every 5 hours, the total caffeine is halved. You must use 
    a loop to simulate this decay. The final output should display the total initial 
    caffeine and the total hours for metabolization.
