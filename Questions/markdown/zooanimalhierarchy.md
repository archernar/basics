## Java Exercises 
### Zoo Animal Hierarchy 

    Create a base class called `Animal` with properties like `name` (String) and `age` 
    (int), and a method called `makeSound()` that prints a generic animal sound. Then, 
    create two subclasses, `Lion` and `Parrot`, that inherit from `Animal`. Override 
    the `makeSound()` method in each subclass to print a specific sound ('Roar!' 
    for the Lion, 'Squawk!' for the Parrot). In your main method, create an instance 
    of a `Lion` and a `Parrot` and call their `makeSound()` methods to demonstrate 
    polymorphism.
