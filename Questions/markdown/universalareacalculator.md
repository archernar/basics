## Java Exercises 
### Universal Area Calculator 

    Create a class `GeometryCalculator` with a set of overloaded static methods all named 
    `calculateArea`. One method should accept a single `double` for the radius 
    of a circle and return its area ($πr^2$). Another version should accept two `double` 
    values for the length and width of a rectangle and return its area. A third 
    version should accept a `double` for the side length of a square. In your main 
    method, demonstrate calling all three versions of `calculateArea` with appropriate 
    arguments and print the results.
