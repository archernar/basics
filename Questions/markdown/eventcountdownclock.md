## Java Exercises 
### Event Countdown Clock 

    Write a program that calculates how many days are left until a specific future event. 
    The program should define a target event date (e.g., New Year's Day of the 
    next year). Using the `java.time` package (`LocalDate` is recommended), get the 
    current date and the target date. The program must then calculate and print the 
    number of days remaining between the current date and the event date.
