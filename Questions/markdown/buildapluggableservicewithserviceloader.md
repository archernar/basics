## Java Exercises 
### Build a Pluggable Service with 'ServiceLoader' 

    Create a simple application with a service provider interface (SPI), for example, 
    an 'ImageEncoder' interface. Create two separate modules/JARs that provide concrete 
    implementations (e.g., 'PNGEncoder', 'JPEGEncoder'). Use 'java.util.ServiceLoader' 
    to discover and load the available encoders at runtime.
