## Java Exercises 
### Dynamic Playlist Manager 

    Design a program to manage a music playlist. The program should allow a user to add 
    a song title, remove a song title by its name, and display all songs in the playlist. 
    Instead of a fixed-size array, you must use an `ArrayList` to store the 
    song titles (which are Strings). The program should present a simple text menu 
    with options to 'add', 'remove', 'display', and 'exit', and loop until the user 
    chooses to exit.
