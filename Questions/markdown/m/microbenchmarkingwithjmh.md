## Java Exercises 
### Microbenchmarking with JMH 

    Use the Java Microbenchmark Harness (JMH) to write a rigorous performance benchmark. 
    Compare the performance of two different implementations of the same logic, 
    for example, iterating over an 'ArrayList' using an index-based for-loop vs. an 
    enhanced for-loop vs. a stream.
