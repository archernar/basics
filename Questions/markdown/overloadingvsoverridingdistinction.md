## Java Exercises 
### Overloading vs. Overriding Distinction 

    Create a 'Parent' class with a method 'compute(int a)'. Create a 'Child' class that 
    extends 'Parent' and adds a new *overloaded* method 'compute(int a, int b)'. 
    The 'Child' class should also *override* the 'compute(int a)' method. Instantiate 
    the 'Child' and call both methods.
