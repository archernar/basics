## Java Exercises 
### Unique Guest List 

    You are creating a system to manage a guest list for an event, ensuring no duplicate 
    names are added. Write a program that uses a `HashSet&ltString&gt` to store 
    the names of guests. The program should repeatedly prompt the user to enter a guest's 
    name. If the name is already in the set, it should print a message saying 
    'Guest is already on the list.' If the name is not present, it should add it to 
    the set and print 'Guest added.' The user can type 'done' to stop entering names 
    and display the final, unique guest list.
