## Java Exercises 
### User Registration Logger 

    Create a program that simulates a user registration system. The program should prompt 
    the user for a new username and a password. It must then create a single string 
    in the format: 'TIMESTAMP,USERNAME,PASSWORD' (e.g., '2025-09-15T22:18:30Z,jdoe,p@ssword123'). 
    This string should then be appended as a new line to a file named 
    'log.txt'. The program should not overwrite existing entries in the file. For 
    the timestamp, you can use Java's `java.time.Instant` class.
