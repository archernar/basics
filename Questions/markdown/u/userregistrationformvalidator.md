## Java Exercises 
### User Registration Form Validator 

    Write a `Validator` class with several static methods for validating user registration 
    data. Create a method `isUsernameValid(String username)` that returns true 
    only if the username is between 6 and 15 characters long. Create another method 
    `isPasswordComplex(String password)` that returns true only if the password is 
    at least 8 characters long and contains at least one number. In your main method, 
    prompt the user for a username and password, use your validator methods to check 
    them, and print appropriate success or error messages.
