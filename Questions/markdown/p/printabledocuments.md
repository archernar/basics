## Java Exercises 
### Printable Documents 

    Define an interface named `Printable` with a single method signature: `void print()`. 
    Create two classes, `Report` and `Email`, that both implement the `Printable` 
    interface. The `Report` class should have a `title` and `content`, and its `print()` 
    method should format and display them. The `Email` class should have `sender`, 
    `recipient`, and `body`, and its `print()` method should do likewise. In 
    your main method, create a list or array containing both `Report` and `Email` objects 
    and loop through it, calling the `print()` method on each object to demonstrate 
    polymorphism.
