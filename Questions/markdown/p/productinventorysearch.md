## Java Exercises 
### Product Inventory Search 

    Create a `Product` class with `productId` (int) and `productName` (String) as fields. 
    In your main program, create an array of at least 10 `Product` objects with 
    unique IDs. Then, write a method `Product findProductById(Product[] inventory, 
    int id)` that performs a **linear search** on the array. The method should return 
    the `Product` object if found, or `null` if no product with the given ID exists. 
    Prompt the user for an ID to search for, call your method, and display the product's 
    name if found, or a 'not found' message.
