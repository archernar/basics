## Java Exercises 
### Preventing Deserialization Vulnerabilities 

    Create a serializable class. Then, using a tool or custom code, create a malicious 
    serialized object (e.g., a 'deserialization bomb' that creates a huge object graph). 
    Implement a look-ahead deserialization proxy or use Java's built-in filtering 
    to prevent the vulnerability.
