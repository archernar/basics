## Java Exercises 
### Prime Number Sieve 

    Write a program that finds all prime numbers up to a user-specified integer 'N'. 
    Your program must be structured using at least two static methods in addition to 
    the main method. 1) A boolean method `isPrime(int number)` that takes an integer 
    as input and returns `true` if it is a prime number, and `false` otherwise. A 
    number is prime if it is greater than 1 and has no divisors other than 1 and itself. 
    2) A void method `findPrimes(int limit)` that takes an integer limit as input. 
    This method should loop from 2 up to the limit, call the `isPrime()` method 
    for each number, and print the numbers that are prime. The `main` method should 
    prompt the user for the upper limit 'N', validate that it's an integer greater than 
    1, and then call `findPrimes()` to display the result.
