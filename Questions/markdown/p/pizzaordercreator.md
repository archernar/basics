## Java Exercises 
### Pizza Order Creator 

    Design a `Pizza` class that can be instantiated in multiple ways. The class should 
    have attributes for `size` (String), `hasPepperoni` (boolean), `hasExtraCheese` 
    (boolean), and `hasMushrooms` (boolean). Create three different constructors: 
    1) A default constructor that creates a 'Medium' pizza with no toppings. 2) A constructor 
    that accepts a `size`. 3) A constructor that accepts a `size` and all 
    three topping choices. Create a `displayOrder()` method to print the pizza's configuration. 
    In main, create a pizza using each constructor to show overloading in 
    action.
