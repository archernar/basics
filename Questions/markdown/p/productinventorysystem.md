## Java Exercises 
### Product Inventory System 

    Combine file I/O, object creation, and data structures. You have a file `inventory.txt` 
    where each line is a product with the format `ID,Name,Price` (e.g., `101,Laptop,1250.0`). 
    Write a program that reads this file, creates a `Product` object 
    for each line, and stores them all in an `ArrayList&ltProduct&gt`. After loading 
    all products, the program should calculate and print the total value of the entire 
    inventory (the sum of all product prices).
