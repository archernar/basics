## Java Exercises 
### Visitor Design Pattern for Abstract Syntax Tree 

    Define a simple expression hierarchy (e.g., 'Number', 'Addition', 'Multiplication' 
    nodes) representing an abstract syntax tree. Implement the Visitor pattern with 
    a 'Visitor' interface and a concrete 'ExpressionPrinter' visitor that can traverse 
    the tree and print the mathematical expression in infix notation.
