## Java Exercises 
### Windowed Stream Processing Simulation 

    Simulate a windowed stream processing engine. Create a stream of time-stamped events 
    (e.g., user clicks). Write a processor that groups these events into tumbling 
    (non-overlapping) time windows (e.g., 10 seconds) and computes an aggregation 
    (e.g., click count) for each window.
