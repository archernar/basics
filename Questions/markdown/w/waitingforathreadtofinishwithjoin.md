## Java Exercises 
### Waiting for a Thread to Finish with 'join()' 

    Create a worker thread that simulates a long task (e.g., by sleeping for 3 seconds). 
    The main thread should start the worker thread, print a message 'Starting worker...', 
    call 'join()' on the worker thread, and then print 'Worker finished.' 
    only after the worker has completed.
