PowerShell Cheatsheet

                
A quick reference for common tasks, translating from the old Command Prompt (CMD) to modern PowerShell.

            

            

                

                    
                        

                            Task
                            Command Prompt (CMD)
                            PowerShell (and Aliases)
                        

                    
                    
                        

                            List Contents
                            dir
                            Get-ChildItem (ls, dir)
                        

                        

                            Change Directory
                            cd <path>
                            Set-Location (cd)
                        

                        

                            Create Directory
                            mkdir <name>
                            New-Item -Type Directory (mkdir)
                        

                        

                            Remove Item
                            del <file> / rmdir <dir>
                            Remove-Item (rm, del, rd)
                        

                        

                            Copy Item
                            copy <src> <dest>
                            Copy-Item (cp, copy)
                        

                         

                            Move Item
                            move <src> <dest>
                            Move-Item (mv, move)
                        

                        

                            Rename Item
                            ren <old> <new>
                            Rename-Item (ren)
                        

                        

                            View File Content
                            type <file>
                            Get-Content (cat, type)
                        

                        

                            Clear Screen
                            cls
                            Clear-Host (cls)
                        

                    
                

            

        


        

            
Your Journey Begins

            
You've mastered the basics. Now, continue your journey by exploring these powerful tools that build on your new command-line skills.

            

                

                    
📦 Winget

                    
Use the Windows Package Manager (`winget`) to install, update, and manage your applications directly from the terminal. It's the fastest way to set up a new machine.

                

                

                    
📜 PowerShell Scripting

                    
Combine commands into `.ps1` script files to automate repetitive tasks, like setting up a new project folder or backing up your work. This is where the real power lies.

                

                

                    
💡 VS Code Integration

                    
Master the `code .` command to open entire projects in Visual Studio Code. Explore its integrated terminal to keep your workflow in one place.
